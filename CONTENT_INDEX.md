# Content Index

This file maps Substack posts, notebooks, exercises and quizzes.

Use it to keep the public learning journey consistent.

## How to read this file

- `Core path folder` must match a folder under `notebooks/core-path/`.
- `Related notebook` is the planned notebook filename inside that core path folder.
- `N/A` means the item is a concept post and does not yet need a notebook.
- Planned notebook filenames do not need to exist until their status changes to `Notebook ready` or `Published`.
