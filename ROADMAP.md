# AI/ML with Python Roadmap

This roadmap is the guided learning path for **Machine Learning Moments**.

The goal is to move from beginner Python to practical AI and machine learning in a structured, notebook-first way.

## Roadmap principles

- Learn by doing.
- Keep examples small before making them realistic.
- Explain concepts in plain English first.
- Use notebooks for teaching, practice and experimentation.
- Build from Python basics to modern AI gradually.
- Treat responsible AI, data quality and governance as core skills, not afterthoughts.

| `real-world-cases/` | Applied examples based on realistic business or public datasets |

| `experiments/` | Early ideas, rough work and future explorations |
